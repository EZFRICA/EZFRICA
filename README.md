### 🚀 &nbsp;Featured Projects
**[Context Lifecycle Engine (CLE)](https://github.com/EZFRICA/context-lifecycle-engine)**: Framework for managing context switching in LLM-based agents, applying OS concepts (process control blocks, TLB, Markov prediction, Merkle DAG stores) to agent memory and context management.

**[Agent Processor Unit (APU)](https://github.com/EZFRICA/Agent-Processor-Unit)**: Open-source four-tier memory hierarchy for AI agents (in-process → Redis → Weaviate → Letta) with a bidirectional metadata routing algorithm, async priority-queue scheduler, and human-in-the-loop override dashboard. Also published as a Medium article series in the Google Cloud Community collection.

**[ALU Sage](https://github.com/EZFRICA/alu-education-agent)**: Offline-first AI education platform for resource-constrained devices in Africa, built with Gemma, LanceDB on-device, and a LangGraph agent. Gemma Hackathon submission.
