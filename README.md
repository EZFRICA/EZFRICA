### 🚀 &nbsp;Featured Projects
 
**[Context Lifecycle Engine (CLE)](https://github.com/EZFRICA/context-lifecycle-engine)**\
Detects recurring intents in a user's prompt history, compiles each into a versioned agent validated by replaying the user's past, and demotes it when the served model drifts. Measured on real corpora, with its limits documented alongside the code.
 
**[Akili](https://github.com/EZFRICA/apu-akili)**\
School tutor built on the APU for sighted and visually impaired pupils, through text, voice and braille. Guard red-teamed with 69 attacks and 14 multi-turn scenarios, interface audited for screen readers, and every model chosen by measurement.
 
**[Agent Processor Unit (APU)](https://github.com/EZFRICA/Agent-Processor-Unit)**\
OS-style memory hierarchy for LLM agents (in-process cache, linked-list working context, Weaviate, Letta) with LRU paging, BMJ routing and an async scheduler. Published as a Medium series in the Google Cloud Community collection.
 
**[Context as a Service](https://medium.com/google-cloud/context-as-a-service-modular-architecture-for-the-age-of-ai-agents-58fbae3ee030)**\
Architecture article (August 2025) on building agents from versioned context blocks promoted from dev to prod.
